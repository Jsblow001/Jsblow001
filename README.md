## 👋 소개

> **"사용자의 편의를 고민하며 탄탄한 백엔드 설계를 지향합니다."**
> 세명대학교 스마트IT학부에서 컴퓨터 과학의 기초를 다졌으며, 실제 서비스의 데이터 흐름과 시스템 부하를 고민하는 개발자가 되기 위해 노력하고 있습니다. 문제를 해결하는 과정 자체를 즐기며, 협업의 가치를 소중히 여깁니다.

* **기본에 충실한 개발:** C, Java 등 다양한 언어 경험을 바탕으로, 데이터 구조와 알고리즘에 대한 깊이 있는 이해를 가지고 있습니다.
* **성과 중심의 문제 해결:** 실제 프로젝트에서 DB 설계 및 쿼리 최적화를 통해 시스템 성능과 무결성을 개선한 경험이 있습니다.
* **성장을 위한 문서화 습관:** 설계부터 트러블슈팅까지 개발의 모든 과정을 투명하게 기록하여 동료와 공유 가능한 지식 자산으로 만듭니다.
